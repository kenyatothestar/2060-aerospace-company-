# 2060 Mission Control — Customer Demo Script

## 1. Introduction

"This is 2060 Mission Control, our software platform for
mission-operations monitoring."

## 2. Mission Dashboard

Show:
- Mission status
- Altitude
- Velocity
- Fuel
- Mission progress

Explain that the current values are simulated demonstration data.

## 3. Telemetry

Open the telemetry interface and explain how mission information
can be presented in a single operational view.

## 4. Spacecraft Systems

Show:
- Power
- Propulsion
- Thermal
- Communications
- Navigation

Explain how a future production system could connect validated
mission data sources.

## 5. Business Value

Ask the customer:

"What mission-monitoring information would you want to see
in a system like this?"

## 6. Close

"We are looking for early pilot users who can help us shape
the product around real operational needs."

## Important

Never describe simulated telemetry as live spacecraft telemetry.
