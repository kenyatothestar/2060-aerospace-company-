# 2060 First Revenue Plan

## Objective

Generate the first legitimate revenue from the software and
related services.

## Initial offers

### Pilot software
Offer selected organizations access to an early Mission Control
pilot for evaluation.

### Custom dashboards
Build monitoring dashboards customized for a customer's needs.

### Simulation and training
Offer mission-control simulation software for education and training.

### Engineering services
Provide software development and integration services while the
main product is being developed.

## Revenue strategy

Start small.

1. Find one real problem.
2. Build a useful solution.
3. Demonstrate it.
4. Obtain a pilot customer.
5. Charge for the pilot or implementation.
6. Use customer feedback to improve the product.
7. Repeat.

## Principle

Revenue comes before large-scale expansion.
Do not promise capabilities the current product does not have.
