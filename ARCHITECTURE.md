# 2060 Mission Control Architecture

## Frontend
The `frontend/` directory contains the Mission Control interface.

## Backend
`server.js` provides the Node.js API server.

## Data
`database.js` provides the current mission data layer.

## Authentication
`auth.js` provides the current authentication foundation.

## Monitoring
Health and system verification scripts provide local operational checks.

## Deployment
`render.yaml` contains the current Node.js deployment configuration.

## Current limitation
Telemetry shown by the prototype is simulated data.
Real aerospace operation would require validated hardware,
secure production infrastructure, extensive testing,
monitoring, safety processes, and applicable regulatory approval.
