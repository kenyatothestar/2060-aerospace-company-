# 2060 Product Priority System

## Priority levels

### P0 — Critical
Required to keep a production service operational or secure.

### P1 — High
Provides major customer value or enables an important pilot.

### P2 — Medium
Useful improvement with meaningful customer benefit.

### P3 — Low
Nice-to-have feature with limited immediate impact.

## Prioritization score

Evaluate each request using:

- Customer impact
- Number of customers affected
- Revenue potential
- Strategic importance
- Implementation effort
- Security impact

## Decision rule

Prioritize features that provide high customer value with
reasonable implementation effort.

Never prioritize a feature solely because it looks impressive.
