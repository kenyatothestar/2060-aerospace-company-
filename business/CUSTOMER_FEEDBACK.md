# 2060 Customer Feedback System

## Feedback record

For each conversation record:

- Organization
- Date
- Contact
- User role
- Problem described
- Current solution
- Desired capability
- Importance
- Willingness to test
- Willingness to pay
- Follow-up date

## Questions

1. What problem are you trying to solve?
2. How do you solve it today?
3. What is difficult about the current process?
4. What information would you want on one screen?
5. Which capability would save the most time?
6. Would you test an early version?
7. Would your organization pay for it?
8. What would prevent adoption?

## Product decision rule

Prioritize requests that:
- Solve a repeated problem
- Affect multiple potential customers
- Provide measurable value
- Can realistically be implemented

Do not build features simply because someone requests them.
