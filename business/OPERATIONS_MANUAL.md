# 2060 Aerospace Systems — Operations Manual

## Purpose

Define the basic operating process for the 2060 Mission Control
software business.

## Daily Operations

1. Check application availability.
2. Check backend/API status.
3. Review system logs.
4. Review customer or pilot activity.
5. Review open issues.
6. Record important changes.

## Product Operations

Before every customer demonstration:

- Confirm the application starts correctly.
- Confirm Mission Control loads.
- Confirm telemetry displays.
- Confirm system-status panels work.
- Confirm simulated-data notices are visible.

## Customer Operations

For every customer:

- Record the organization.
- Record the primary contact.
- Record requirements.
- Record agreed scope.
- Record next action.
- Keep customer information secure.

## Change Management

Before changing production software:

1. Test the change.
2. Commit the change to Git.
3. Record what changed.
4. Verify the application.
5. Keep a rollback option.

## Principle

Never make untested changes to a customer-facing production
system.
