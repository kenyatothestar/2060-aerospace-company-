# 2060 Intellectual Property Protection Checklist

## Company identity

- [ ] Confirm company name availability
- [ ] Review trademark strategy
- [ ] Protect important brand assets

## Software

- [ ] Maintain Git history
- [ ] Record authorship
- [ ] Document major releases
- [ ] Review open-source licenses
- [ ] Protect private source code

## Confidential information

- [ ] Identify confidential information
- [ ] Restrict access
- [ ] Use NDAs when appropriate
- [ ] Never publish private credentials

## Inventions

- [ ] Record significant technical inventions
- [ ] Date important development records
- [ ] Consult qualified IP counsel before public disclosure
  where patent protection may be relevant

## Ownership

- [ ] Confirm founder ownership
- [ ] Document contractor assignments
- [ ] Document employee IP agreements
- [ ] Keep company records organized

## Principle

Protect valuable intellectual property while avoiding
unnecessary legal complexity at the prototype stage.
